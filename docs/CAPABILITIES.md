# What works where

Generated by `python run.py --capabilities` from the tools that are really registered.

## Features

| Feature | Works | Needs |
|---|---|---|
| Chat and tool use with a local model (Ollama) | offline after setup | Ollama + a downloaded model |
| Wake word, speech recognition | offline after setup | speech models downloaded once; a microphone |
| Spoken replies (Piper / Kokoro voices) | offline after setup | voice files downloaded once |
| Neural Edge voices (en-GB-Ryan, bn-BD) | internet | Microsoft's online voice service; falls back to Piper |
| Open / arrange / close apps and windows | offline | Windows |
| Files: find, duplicates, batch rename with preview, zip | offline | folders you allow |
| Screen reading (OCR) and window overview | offline | Windows OCR / installed OCR engine |
| Screenshot understanding (vision model) | offline after setup | a vision model in Ollama |
| Memory, journal, habits, expenses, to-dos, reminders | offline | the local database |
| Local document search (full text) | offline | folders you index |
| Semantic document search (embeddings) | offline after setup | an embedding model in Ollama |
| Automations, workflows, missions, scheduler | offline | Jarvis running (or the background host) |
| System monitor, PC health, diagnostics | offline | Windows; GPU figures need nvidia-smi |
| JARVIS Mobile: chat, approvals, cancel, phone link | local network | paired phone on the same Wi-Fi |
| Phone flashlight / ring / open app (phone link) | local network | JARVIS Mobile with 'Let my PC control this phone' on |
| Phone notifications on the PC | local network | Android notification access (you grant it on the phone) |
| Instant phone updates while the app is open (no Firebase) | local network | JARVIS Mobile 1.1 open on the phone |
| See / tap the phone's screen from the PC | local network | JARVIS Mobile 1.1: Share screen (Android asks each time); taps need its Accessibility service |
| Phone: call, SMS, read messages, contacts, gallery / camera | local network | JARVIS Mobile 1.2 with 'Allow calls and messages' + Android permissions; calls/SMS ask you first |
| Keep your voice commands to train the recognizer | offline | SPEECH_DATASET on; training needs a GPU |
| Wake another PC (Wake-on-LAN) | local network | wired network + WoL enabled in the PC's BIOS |
| Smart home (Home Assistant) | local network | your Home Assistant URL + token |
| Web search, news, weather, research | internet | internet |
| Outlook calendar and mail | hardware / OS permission | classic Outlook desktop app signed in (mail sync needs internet) |
| Google Calendar / Drive | credentials | your own Google OAuth client id (optional, off by default) |
| GitHub (issues / pull requests) | credentials | a GitHub token (optional) |
| Push wake-ups to the phone (FCM) | credentials | your own Firebase service account (optional) |
